# Bun Bun boot splash (Plymouth theme "bunbun")

Replaces the upstream Bazzite boot splash with the Bun Bun logo mark: a
pink-and-white bunny with the cyan AI-visor accent, centered on a dark
navy-to-plum background. The theme is the stock two-step plugin, so the boot
progress behaviour the Deck image expects is unchanged.

Both build paths install it and point the system default at it:

- packaging/bazzite/Containerfile        (the installed deck payload)
- packaging/bazzite/Containerfile.live   (the live installer medium)
