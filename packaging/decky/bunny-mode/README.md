# Bunny Mode (pre10 pillar 1 scaffold)

Bun Bun crosses between desktop mode and Game Mode, and the bunny theme
follows her. This plugin watches the session switch (gamescope = Game Mode,
plasmashell = desktop on Bazzite) and flips the theme with her.

Build 2 wires the real CSS Loader profile toggle into `_apply_theme_profile`.
