Pick your hardware

Four images exist, one per machine type. Download the one that matches yours:

  • Steam Deck LCD - ready, download below.
  • Steam Deck OLED - variant in build today.
  • AMD handheld or desktop PC - variant in build today.
  • NVIDIA RTX handheld or PC - building right now, lands later today.

Not sure which you have? Steam Deck LCD and OLED look almost identical; check Settings, System, Model. Handhelds with AMD chips (most ROG Ally and Legion Go models) take the AMD image; ones with an NVIDIA RTX chip take the NVIDIA image.

Steam Deck LCD ISO (full image)

BunBunOS-deck-lcd-0.2.0.iso, about 7.2 GB total. It ships as 4 parts; grab all four, join them in order, then check the checksum.

  • Part 1
  • Part 2
  • Part 3
  • Part 4
  • Checksum (.sha256)

Join the parts:

windows copy /b BunBunOS-deck-lcd-0.2.0.iso.01.part+BunBunOS-deck-lcd-0.2.0.iso.02.part+BunBunOS-deck-lcd-0.2.0.iso.03.part+BunBunOS-deck-lcd-0.2.0.iso.04.part BunBunOS-deck-lcd-0.2.0.iso linux/mac cat BunBunOS-deck-lcd-0.2.0.iso.??.part > BunBunOS-deck-lcd-0.2.0.iso

Flash it: Rufus in ISO Image mode (not DD mode) on Windows, or dd on Linux. On the Deck: power off, hold Volume Down, press Power, pick the USB device. Secure Boot off.

Portable panel (no parts, one file)

Already running Bazzite? This small tarball installs the Bun Bun panel into your existing system without touching the bootloader, kernel or account.

  • bunny-os-portable-0.2.0.tar.gz (+ checksum)
tar xzf bunny-os-portable-*.tar.gz -C /tmp sudo /tmp/bunny-os-portable-*/install.sh

Why parts?

Free hosting caps any single file at 2 GB, and a full OS image is bigger than that. Every host on a budget has the same rule, so the ISO ships as parts that fuse back into one file with a single command. The checksum proves the result is intact.
