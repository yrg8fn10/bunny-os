What is Bun Bun OS?

A handheld-first operating system built on Bazzite, wrapped around a warm pastel shell and a bilingual AI companion named Bun Bun. It boots straight into a game console experience, greets you when you wake up, and keeps a little dark-pocket magic just below the surface.

The shell, in layers

Layer A, look and feel. Pastel themes for the boot splash and the desktop around stock Steam. Nothing is patched; the base system stays untouched.
Layer B, the session. Bun Bun's d-pad overlays and the companion call button. Works even when a Steam update outpaces the theme.
Layer C, Big Picture. Decky Loader sits inside Game Mode so Bun Bun really lives there: a CSS theme plus a d-pad shelf plugin.

Status

Early days, v0.1 alpha. ISO builds are running now; when one goes green it lands on the download page with a direct download link. Every install is checked by the bunny-verify hooks.
